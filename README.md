# Bounty Hunting Journal

A working log of the path from zero to a first real finding — what was
studied, what was built, what was attempted, and what the results
actually were.

## What this journal is

- A dated record of learning and attempts, kept while the work is in
  progress.
- A place to record failures and dead ends alongside successes, because
  both are information.
- The home of the skill curriculum and its honest status markers.

## What this journal is not

- It is not a portfolio of achievements. Early entries document a
  starting point, not results.
- It is not a record of findings. Verified findings, if any ever exist,
  belong in the `bug-bounty-reports` repository.
- It contains no submission codes, claim codes, or private details of
  any bounty entry. Participation in programs is described in general
  terms only.

## The curriculum

[CURRICULUM.md](CURRICULUM.md) lays out four levels — fundamentals,
security analysis, security tools, and real bounty hunting — as
checklists with honest status markers. Status is updated only when the
work is actually done.

## Rules for entries

1. Dates are real. An entry is written on the day it describes, or
   says so if it is not.
2. Status markers mean what they say. "Done" requires the work to
   exist. "Started" requires the work to have begun. Everything else is
   "Not started."
3. Results are reported as they happened, including rejections and
   failures.
4. No entry claims expertise, audit experience, or findings that do
   not exist.
